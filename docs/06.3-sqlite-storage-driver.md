# SQLite PRAGMA

Configure

PRAGMA foreign_keys = ON

PRAGMA journal_mode = WAL

PRAGMA synchronous = NORMAL

PRAGMA temp_store = MEMORY

PRAGMA cache_size = -64000

These should execute automatically during initialization.

# SQLiteBatchWriter

Responsible for

converting immutable Storage Records into SQL INSERT statements.

Use executemany where appropriate.

Write batches inside a single transaction.

Never reorder records.

---

# Batch Guarantees

Batches are atomic.

Either

all rows are written

or

no rows are written.

Never partially commit.

---

# Thread Safety

Protect mutable driver state using threading.RLock.

Do not serialize unrelated readers.

Maintain correctness.

---

# Error Handling

# Performance
