# TraceForge CLI Reference

- `traceforge init [dir]`: Initialize project workspace
- `traceforge server`: Start HTTP Gateway server
- `traceforge replay <session_id>`: Reconstruct execution session
- `traceforge diff <base_id> <target_id>`: Compare execution sessions
- `traceforge export <session_id>`: Export artifact (JSON, Mermaid, HTML, Markdown)
- `traceforge visualize <session_id>`: Output graph/timeline/flamegraph model
- `traceforge config`: Display active configuration
- `traceforge version`: Print system version info
