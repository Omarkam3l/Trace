# TraceForge REST API Reference

- `GET /api/v1/sessions`: List sessions
- `GET /api/v1/sessions/{id}`: Get session
- `GET /api/v1/sessions/{id}/replay`: Replay session
- `POST /api/v1/diff`: Compare sessions
- `GET /api/v1/sessions/{id}/export`: Export session
- `POST /api/v1/diff/export`: Export diff
- `GET /api/v1/sessions/{id}/visualization/graph`: Graph view model
- `GET /api/v1/sessions/{id}/visualization/timeline`: Timeline view model
- `GET /api/v1/sessions/{id}/visualization/flamegraph`: Flamegraph view model
- `GET /api/v1/health`: Health status
- `GET /api/v1/metrics`: Metrics JSON
